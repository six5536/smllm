# Code of conduct

This code sets out how everyone who takes part in smllm treats each other. It describes the
behaviour that the project expects and the behaviour that it doesn't accept, where the code
applies, and how to report a breach.

- [Our pledge](#our-pledge)
- [Expected behaviour](#expected-behaviour)
- [Unacceptable behaviour](#unacceptable-behaviour)
- [Scope](#scope)
- [Reporting](#reporting)
- [Attribution](#attribution)

## Our pledge

We, the maintainers, want smllm to be a project that anyone can take part in. Everyone involved,
including contributors, maintainers, and people who open issues, helps to keep it that way.

## Expected behaviour

- Be respectful. Disagree with the idea, not the person.
- Assume good faith. Most confusion comes from a missing explanation, not from bad intent.
- Accept feedback graciously, and give it kindly.
- Keep discussion on the work.

## Unacceptable behaviour

- Harassment, insults, or personal attacks.
- Discriminatory comments about anyone's identity or background.
- Publishing someone's private information without permission.
- Sustained disruption of discussions.

## Scope

This code applies in every space of the project, such as issues, pull requests, discussions, and
commit messages. It also applies whenever someone represents the project elsewhere.

## Reporting

To report a problem in private, email the maintainer at the address on their
[GitHub profile](https://github.com/six5536). If you would rather not use email, open a
[private security advisory](https://github.com/six5536/smllm/security) instead.

The maintainer handles each report in confidence and responds as quickly as they reasonably can.
The maintainer can warn, temporarily block, or permanently ban anyone whose behaviour breaches
this code.
