# tutorials

- [Check the agent's work][sokf:tutorial-check-the-agents-work] - Write a state machine that runs a test before the agent can finish, sends the agent to the user after repeated failures, and records why the test failed.
- [Connect an agent][sokf:tutorial-connect-an-agent] - Install smllm into Claude Code, and follow a state machine as the agent sees it, from the start of a session to the end of the work.
- [Your first state machine][sokf:tutorial-first-machine] - Write a state machine that guides an agent through a bug fix, check it, and drive it as the agent does.
- [Run the engine in Node.js][sokf:tutorial-run-the-engine-in-node] - Compile a state machine to JSON, and drive it from a Node.js script with the engine of `@six5536/smllm-wasm`.
